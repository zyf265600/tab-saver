# Tab Saver

自动休眠长时间没看的 Chrome 标签页，释放内存。休眠的标签页仍然留在标签栏里，点一下就会重新加载。

## 功能
- **自动休眠**：标签页超过设定时间没被查看就自动休眠（5 分钟 – 4 小时可调）
- **一键休眠**：立即休眠当前窗口 / 所有窗口的其他标签页
- **一键唤醒**：把当前窗口 / 所有窗口里休眠的标签页全部重新加载（在后台加载，不会切换标签页）
- **休眠标识**：休眠前在网页图标外面加一圈虚线，并在标题前加上 💤，一眼就能看出哪些标签页在休眠；点开后网页重新加载，图标和标题自动恢复（PDF、Chrome 应用商店等不允许扩展改动的页面没有这个标识，但照样会休眠）
- **白名单**：白名单里的网站（包括子域名）永远不会被休眠，可一键添加当前网站

以下标签页始终不会被休眠：当前正在看的、固定的、正在播放声音的、`chrome://` 等内部页面。

## 安装
1. 打开 `chrome://extensions`
2. 打开右上角 **开发者模式（Developer mode）**
3. 点 **加载已解压的扩展程序（Load unpacked）**，选择这个 `tab-saver` 文件夹
4. 点工具栏的拼图图标，把 Tab Saver 固定到工具栏

需要 Chrome 121 或更新版本。为了替换网页图标，扩展需要“读取和更改所有网站上的数据”权限（只用来换图标，不读取网页内容）。所有设置只存在浏览器里（`chrome.storage.sync`），不联网、不收集数据。

## 文件
- `manifest.json`：扩展清单（Manifest V3）
- `background.js`：后台 Service Worker，每分钟检查一次闲置标签页
- `shared.js`：休眠规则、白名单匹配，后台和弹窗共用
- `popup.html / popup.css / popup.js`：弹窗界面
- `icons/`：图标

修改代码后，在 `chrome://extensions` 里点 Tab Saver 卡片上的刷新按钮即可生效。
